# Paper Reading Notes Skill

一个用于科研论文精读、对比与复习笔记整理的 **AI Agent Skill**，帮助将学术论文转化为**通俗、准确、可脱离原文独立复习**的中文笔记，并在完整精读时附带可直接用于组会分享的**五分钟讲解稿**。

---

## 核心特性

- **先讲问题，再讲方法**：严格遵循 `研究问题 → 现有不足 → 核心思路 → 方法机制 → 实验验证 → 结论与局限` 的叙事主线，不堆砌模块名词。
- **忠于原文，严禁脑补**：明确区分「论文明确报告的事实」「基于原文的合理推演」与「延伸思考」，不凭经验补造实验细节或数值；材料不完整时主动声明依据范围。
- **讲清机制与证据对齐**：拆解模块必交代 `输入 → 处理 → 输出 → 衔接关系 → 设计动机`；汇报实验必绑定比较对象、数据集、指标含义与测试条件。
- **覆盖多种论文类型**：针对 **Benchmark / Dataset**、**方法 / 模型**、**Agent**、**Survey / Review** 分别提供专属拆解视角。
- **多种复习与交流模式**：支持完整复习笔记（含 900–1200 字五分钟口头讲解稿）、快速了解、通俗讲解、组会/导师交流准备、考前速记及多篇论文横向梳理。

## 安装方式

将本仓库克隆或复制到支持 Agent Skills 规范的工具目录中即可使用（支持 Antigravity、Claude Code 等）：

### 方式一：安装到当前项目（推荐用于团队共享）

```bash
# Antigravity 项目级 Skill 目录
git clone https://github.com/linzch23/paper-reading-notes.git .agents/skills/paper-reading-notes
```

### 方式二：安装到全局配置（所有项目通用）

```
帮我安装这个 skill：https://github.com/linzch23/write-notes
```

## 使用示例

直接向 Agent 发送论文 PDF、arXiv 链接、文本片段，并配合以下自然语言指令即可触发不同模式：

| 场景 | 示例指令 | 输出说明 |
| :--- | :--- | :--- |
| **单篇精读（默认）** | “帮我把这篇论文总结成复习笔记” | 输出完整 8 节结构化笔记 + **900–1200 字五分钟讲解稿** |
| **快速了解** | “这篇论文做了什么？给我宏观讲讲” | 一句话概括 + 问题 + 核心方案 + 关键结果 + 最大局限 |
| **通俗讲解** | “方法第 3 节没看懂，再通俗一点解释” | 从具体场景与直觉切入，精准重讲未理解部分 |
| **组会 / 导师交流** | “帮我基于这篇论文准备组会汇报” | 聚焦动机贡献、关键取舍、强证据、潜在漏洞与讨论问题 |
| **考前速记** | “把这篇论文压缩成考前速记卡片” | 提炼 6 个核心模块并保留因果逻辑链 |
| **多篇论文梳理** | “对比这 3 篇论文的思路和局限” | 逐篇统一口径总结 + 跨论文联系对比 + 方向性小结 |
| **先确认结构** | “先给我目录” | 仅输出笔记结构目录并等待确认 |
